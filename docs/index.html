Overview

LapseCoin is peer-to-peer electronic cash. Block production is secured by a Verifiable Delay Function (VDF) instead of proof-of-work mining, and transactions are signed with FALCON-512, a quantum-resistant signature scheme.

  • Consensus: the chain with the most cumulative proven VDF work wins, Bitcoin-style. Each block takes about 120 seconds of sequential computation.
  • Transactions: ordinary, plaintext transfers with sender-bid fees and an optional short public memo.
  • Supply: capped at 21 million LAPSE with smooth exponential decay (about a 20-year half-life) and no halvings.
  • Addresses: twelve-word phrases derived from the public key.
  • Open source: github.com/Lapsecoin/core

Nodes also include an in-app Market (beta) for peer-to-peer swaps. See the README for details.

Running a Node

The recommended way is a pre-built binary from the releases page. Building from source needs native libraries (liboqs, chiavdf) that can be awkward to compile on some platforms.

./lapsecoin            # Linux
lapsecoin.exe          # Windows

You are prompted for a signing passphrase. The wallet UI is then at http://localhost:8335. For headless setups, set LAPSECOIN_PASSPHRASE and pass --no-gui.

PortInterfacePurpose
8333 (--port)0.0.0.0Peer traffic (UDP) and the public read-only node UI and API (TCP). Safe to expose.
8335 (port+2)127.0.0.1Private wallet UI, including Send. Never expose.
8336 (port+3)0.0.0.0Reserved for the DHT subsystem (libtorrent).
18334LANFixed port for same-network peer discovery.

Full CLI options and environment variables are in the README.
