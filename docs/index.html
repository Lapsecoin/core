Overview

LapseCoin is a peer-to-peer network for decentralized exchanges and trading. Nodes run markets, match orders, and settle trades on-chain.

  • Node network: P2P gossip protocol, no central server
  • Markets: Each node runs order books and automatic matching
  • Settlement: Atomic transactions on the blockchain
  • Open source: github.com/Lapsecoin/core
Documentation
  • API Reference - Node endpoints, info, address queries, transaction broadcast
  • Exchange Integration - Bitcoin Core RPC mapping, deposit handling, cold storage
  • Transactions - Signing spec, address derivation, Python examples, deposit detection
Running a Node
git clone https://github.com/Lapsecoin/core
cd core
python -m pip install -r requirements.txt
python main.py

Node serves:

  • HTTP API on port 8333 (public, no auth)
  • P2P gossip on port 15234 (UDP, peer discovery)
  • GUI on localhost:8334 (local only)
