Public API Endpoints

Base URL: http://lapsenode.vicnas.me:8333 (or your node address)

GET /api/info
Network and node statistics
Response
FieldTypeDescription
heightintegerCurrent block height
mempool_sizeintegerPending transactions in mempool
peer_countintegerConnected peers
sync_percentfloatSync progress (0-100)
sync_targetintegerTarget height during sync
circulatingintegerTotal circulating ticks
block_rewardintegerCurrent block reward in ticks
network_age_secondsintegerSeconds since genesis
total_mintedintegerTotal ticks minted (cap: 21M LAPSE)
burnedintegerTotal ticks burned (fee destruction)
Example
curl http://lapsenode.vicnas.me:8333/api/info
{
  "height": 12345,
  "mempool_size": 42,
  "peer_count": 8,
  "sync_percent": 100,
  "circulating": 5000000000000,
  "block_reward": 500000000,
  "network_age_seconds": 31536000
}
GET /api/block/{height}
Get block by height
Parameters
NameTypeDescription
heightintegerBlock height
Example
curl http://lapsenode.vicnas.me:8333/api/block/12345
GET /api/tx/{hash}
Get transaction by hash
Parameters
NameTypeDescription
hashstringTransaction hash (hex)
GET /api/address/{addr}/valid
Check if address is valid
Response
FieldType
validboolean
GET /api/address/{addr}/balance
Get address balance
Response
FieldTypeDescription
balanceintegerBalance in ticks
confirmedintegerConfirmed balance in ticks
pendingintegerPending balance in ticks
GET /api/address/{addr}/history
Get address transaction history
Response
FieldTypeDescription
sentarraySent transactions (includes pending)
receivedarrayReceived transactions
Nonce Lookup

No /api/address/{addr}/nonce endpoint exists. To find the next nonce for sending:

  1. Call /api/address/{addr}/history
  2. Count entries in the sent array
  3. Next nonce = count (zero-indexed: first tx uses nonce 1)
GET /api/mempool
Get current mempool transactions
Response
FieldType
transactionsarray
POST /api/tx/send
Broadcast a signed transaction
Request Body (JSON)
FieldTypeDescription
tx_datastringSerialized transaction (hex)
signaturestringTransaction signature (hex)
Response
{
  "status": "accepted" or "rejected",
  "message": "reason if rejected",
  "tx_hash": "transaction hash if accepted"
}
GET /api/fees
Get fee estimates
Response
FieldTypeDescription
slowintegerTicks per byte (slower confirmation)
standardintegerTicks per byte (normal)
fastintegerTicks per byte (faster)
GET /api/peers
Get known peer addresses for P2P connection
Notes
  • No CORS headers. Call API from a server, not the browser.
  • All amounts in ticks (1 LAPSE = 10000 ticks).
  • Addresses are one per node instance (stateful).
  • Memo field acts as a deposit tag for exchange routing.
