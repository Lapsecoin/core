Transaction Signing
Format

Transactions are built as CSV (comma-separated) and signed with EdDSA (Ed25519).

CSV Structure
to_addr_1, amount_1, memo_1
to_addr_2, amount_2, memo_2
...

Each line represents one output (recipient). Amounts are in ticks (integers only).

Signing Process
  1. Build outputs CSV (each line is address,amount_ticks,memo)
  2. Concatenate: nonce|outputs_csv (pipe-separated)
  3. Sign the concatenated string with node's private key (Ed25519)
  4. Encode both as hex
  5. POST to /api/tx/send with fields: tx_data (hex of outputs) and signature (hex of signature)
Nonce

Each transaction uses a sequential nonce starting at 1 (not 0). Nonce must be sender's last confirmed nonce plus one. To find it:

  1. Call GET /api/address/{addr}/history
  2. Count the number of transactions in the sent array
  3. Next nonce = count + 1 (first tx uses nonce 1)
Address Derivation
  • Scheme: Ed25519 public key, encoded in Bech32
  • Format: lapse1... prefix
  • Derived from the node's private key on startup
  • One address per node instance (persistent, non-fungible per instance)
Python Reference Implementation
Building and Signing
import nacl.signing
import nacl.encoding

# Load your private key (32 bytes, hex)
private_key_hex = "..."
private_key = nacl.signing.SigningKey(
    bytes.fromhex(private_key_hex)
)
public_key = private_key.verify_key

# Build transaction
nonce = 1
outputs = [
    ("lapse1abcd...", 1000000, "user123"),
    ("lapse1efgh...", 2000000, "user456")
]

# CSV format outputs
outputs_csv = "\n".join(
    f"{addr},{amount},{memo}"
    for addr, amount, memo in outputs
)

# Sign: nonce|outputs_csv
message = f"{nonce}|{outputs_csv}"
signature = private_key.sign(message.encode()).signature

# Send
tx_data_hex = outputs_csv.encode().hex()
signature_hex = signature.hex()

import requests
resp = requests.post(
    "http://lapsenode.vicnas.me:8333/api/tx/send",
    json={
        "tx_data": tx_data_hex,
        "signature": signature_hex
    }
)
print(resp.json())
Address Derivation
import nacl.signing
import bech32

# Private key to address
private_key_hex = "..."
signing_key = nacl.signing.SigningKey(
    bytes.fromhex(private_key_hex)
)
public_key_bytes = signing_key.verify_key.encode()

# Encode as Bech32 with "lapse" prefix
address = bech32.bech32_encode("lapse", bech32.convertbits(
    public_key_bytes, 8, 5
))
print(address)  # lapse1...
Deposit Detection Sketch
import time

address = "lapse1..."  # Your node's address
node_url = "http://lapsenode.vicnas.me:8333"
last_tx_count = 0

def check_deposits():
    global last_tx_count
    
    # Get address history
    resp = requests.get(f"{node_url}/api/address/{address}/history")
    history = resp.json()
    
    received = history.get("received", [])
    
    if len(received) > last_tx_count:
        # New deposits
        new_txs = received[last_tx_count:]
        for tx in new_txs:
            memo = tx.get("memo", "")
            amount_ticks = tx.get("amount", 0)
            amount_lapse = amount_ticks / 10000
            
            print(f"Deposit: {amount_lapse} LAPSE (memo: {memo})")
            # Route to user based on memo
            route_to_user(memo, amount_lapse)
        
        last_tx_count = len(received)

while True:
    check_deposits()
    time.sleep(30)  # Check every 30 seconds
Notes
  • All amounts in ticks (integers). 1 LAPSE = 10000 ticks.
  • Memo field is required but can be empty ("").
  • Use memo to route deposits to exchange user accounts.
  • Nonce increments with each transaction. Reusing nonce is a double-spend error.
  • Signature is Ed25519 (not ECDSA). Ensure your signing library uses the correct scheme.
