How to read this
  • Speed is the VDF iterations a block carried divided by the time since the previous block, so a retarget changes nothing. It is the median over every block the machine built, and ± is the standard error of that median.
  • Machine is whatever CPU a builder declared. It cannot be checked, so a row backed by one builder is marked low. A machine that declared nothing is not listed.
  • The figure includes the time a block takes to travel, so it sits a little under the raw VDF speed (compare This machine, measured here with no network). A machine only shows on blocks it won, so slower ones read a little faster than they are.
  • ≥ marks a machine so fast that most of its blocks were stamped at the {{ floor }} second timestamp floor, which hides how much faster it is.
