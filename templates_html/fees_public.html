How to use it
  1. Get the wallet from the releases page.
  2. Have {{ lock }} LAPSE: mine it, or get some free on Discord.
  3. Open Fees in your wallet (localhost:{{ private_port }}/fees), pick the network and paste the address.

The {{ lock }} LAPSE keeps fake requests out: it returns to you if no node offers to help, and is burned if one does. To serve requests yourself, fund your node's Base address (shown on the Send page).
