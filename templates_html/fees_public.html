Fees

Gas for any network, paid by a node

Holding a token but no coin to move it? Ask the network for gas. A node operator sends the native coin to your address on the chain you pick, so your transaction can go through. Available on {{ networks|length }} networks, including {% for n in networks[:6] %}{{ n.name }}{{ ", " if not loop.last }}{% endfor %} and Solana. A request covers one action, up to about ${{ "%.0f"|format(cap_usd) }} of gas.

How to use it
  1. Get the wallet from the releases page (a full node, or the light client).
  2. Have {{ lock }} LAPSE. Mine it by running a node, or get some free on Discord.
  3. Open Fees in your wallet (http://localhost:{{ private_port }}/fees on a full node). Pick the network, what you want to do, and paste the address that needs gas.
  4. Confirm with your passphrase. Within a few blocks a node sends the gas, and the page shows where it stands.
About the {{ lock }} LAPSE

The LAPSE is a lock that keeps the service from being flooded by fake requests: asking costs something real, and LAPSE is earned by mining or given away on Discord. If no node offers to help within a few blocks, the lock returns to you. If a node offers, it is burned, and the burned coins flow back to block builders over time. Nobody is paid directly for a request.

Help others

Any full node can serve requests. Send some ETH on Base to the address shown on the Send page of your wallet (Base tab) and your node starts answering them. Leave it empty and it never does.
