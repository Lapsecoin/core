# Security

Found a vulnerability? Please report it privately through GitHub's
[Report a vulnerability](https://github.com/Lapsecoin/core/security/advisories/new) form,
or message a maintainer on [Discord](https://discord.gg/FP2d8JmK6r) and ask for a private channel.

Please don't open a public issue until it's fixed. We'll acknowledge reports as quickly as we can.
